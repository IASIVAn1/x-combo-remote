# x-combo-remote
VNC с буфером обмена, звуком, и микрофоном

А точнее скрипт, который позволяет удобно запускать обычный VNC и приложения, предоставляющие функционал, которого не хватает в VNC.
Всё сетевое взаимодействие завёрнуто внутрь SSH - что значительно сужает настройку firewall и прочие вопросы безопасности.

## Как использовать
**1. Требования.**  
Удалённый узел должен быть доступен Вам через SSH. Входить под обычной учётной записью, под той же, что Вы используете на рабочем столе. root-права не нужны.
Скрипту нужны эти команды, но он сам проверит их наличие. Если чего-то не хватает - сообщит. Убедитесь что они работают. Если нет - установите недостающие приложения или исправьте окружение.
`xtightvncviewer`, `ssh`, `rm`, `pkill`, `kill`, `pgrep`, `grep`, `ss`, `screen`, `sleep`, `xsel`, `date`, `pactl`, `x11vnc`, `screen`

**2. Скачать.**  
Весь мой скрипт в одном файле. Просто скачайте его через браузер или прямо в терминале. Не забудьте сделать его исполняемым.
```
curl https://raw.githubusercontent.com/IASIVAn1/x-combo-remote/refs/heads/main/x-combo-remote.sh -O
chmod +x x-combo-remote.sh
```

**3. Пуск**  
Запускайте с указанием адреса удалённого узла так же как если подключаетесь через обычный SSH.
```
./x-combo-remote.sh 192.168.0.2
./x-combo-remote.sh root@server2.local
```
Если Вам нужны дополнительные параметры SSH вроде кастомного порта - можете тоже их указать. В таком случае возьмите в кавычки, чтобы для скрипта это был один аргумент.
```
./x-combo-remote.sh "nastya.mirnaya@ivanet.pro -p 50022"
```
